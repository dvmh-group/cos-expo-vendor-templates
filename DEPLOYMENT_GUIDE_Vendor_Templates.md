# COS Fitness Expo Vendor Templates — Deployment Guide

## What You've Got

Two files ready to deploy to vendors and sponsors:

1. **COS_Expo_Vendor_Templates_Toolkit.html** — Visual gallery of all 10 templates (open in browser, shows designs with copy guidance)
2. **CANVA_SPECS_Vendor_Templates.md** — Detailed copy specs, font sizes, color codes, and caption ideas (text reference document)

---

## How to Deliver to Vendors

### Option 1: Host the HTML on Vercel (Recommended)
The HTML file can be deployed instantly to Vercel (same as the Intake Form).

**Steps:**
1. Upload `COS_Expo_Vendor_Templates_Toolkit.html` to GitHub
2. Deploy to Vercel with one click
3. Share the live URL with vendors
4. They can view, screenshot, or adapt

**Result:** `vendors-templates.vercel.app` (or similar)

### Option 2: Email as Attachment
Send both files directly to vendors via email.
- HTML opens in any browser
- Markdown can be viewed in email or pasted into Google Doc for easier reading

### Option 3: Google Drive Folder
Create a shared Google Drive folder with:
- HTML file (can view in Drive preview)
- Markdown file (can view as doc)
- Any design templates (.psd, .canva links, etc. if you create them)

**Easiest for vendors** — they can bookmark one folder, access all resources.
